Freedom VPN на компьютере

Windows и macOS — через бесплатное приложение Happ. Займёт 2 минуты.

Скачать Happ для Windows

Откройте скачанный файл setup-Happ.x64.exe и установите программу. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

Установить Happ из App Store Happ для зарубежного Apple ID

Если приложения нет в App Store — см. ниже.

Как подключить

  1. Установите Happ по кнопке выше и один раз откройте его.
  2. Откройте бота @Topfreedom_bot или личный кабинет на этом компьютере и нажмите «Подключиться». Откроется страница вашей подписки.
  3. Выберите Windows или macOS и приложение Happ, нажмите «Подключиться» и разрешите открыть Happ. Серверы появятся в списке сами.
  4. Выберите «⚡ Авто — лучший сервер» и нажмите кнопку подключения. При первом запуске система попросит разрешение: в Windows нажмите «Да», на Mac — «Разрешить» и введите пароль.
Новый пользователь? В боте или личном кабинете можно включить 7 дней бесплатно.

Если что-то не получается

Кнопка «Подключиться» не открывает Happ

На странице подписки нажмите «Получить ссылку» и скопируйте её. В Happ нажмите «+» и выберите вставку из буфера обмена.

Happ нет в App Store (Mac)

Попробуйте вторую кнопку — Happ для зарубежного Apple ID. Для неё нужен Apple ID другой страны: в App Store нажмите своё имя внизу слева → «Выйти», войдите зарубежным Apple ID, установите Happ и верните свой Apple ID. iCloud при этом не трогайте.

Подключено, но сайты не открываются

В Happ обновите подписку (значок обновления у её названия) и выберите «⚡ Авто». Если не помогло — выключите и снова включите подключение или перезапустите Happ.

Linux, Android TV, Apple TV

Откройте бота, нажмите «Подключиться» и выберите своё устройство — там есть инструкции и для них.
